# Screen-Time-and-App-Usage-Dataset
This project analyzes screen time and app usage data to understand digital device usage patterns. It explores daily screen time, app-wise usage, frequently used applications, and trends through data analysis and visualization. The project provides meaningful insights into user behavior and helps identify usage patterns.

📱 Screen Time and App Usage Dataset Analysis
📌 Overview
The Screen Time and App Usage Dataset Analysis project explores digital device usage patterns by analyzing screen-time and application-usage data.
The project focuses on understanding how users spend time on their devices, which applications are used most frequently, and how usage patterns vary across different days or time periods. Data analysis and visualization techniques are used to transform raw usage data into meaningful insights.

🎯 Objectives
The main objectives of this project are:
   1. Analyze daily screen-time usage.
   2. Examine app-wise usage patterns.
   3. Identify the most frequently used applications.
   4. Understand trends in digital device usage.
   5. Compare usage across different days or categories.
   6. Create meaningful visualizations from the dataset.
   7. Generate insights that can help understand digital behavior. 
    
📂 Dataset
The dataset contains information related to screen time and application usage.
Typical attributes may include:
  1. Date/Day – Date or day of usage.
  2. App Name – Name of the application.
  3. Usage Time – Time spent using an application.
  4. Screen Time – Total device usage for a particular day.
  5. Notifications – Number of notifications received.
  6. App Opens – Number of times an application was opened.

Note: The exact columns may vary depending on the version of the dataset being analyzed.

🔍 Analysis Performed
The project performs several types of analysis, including:
 1. Daily Screen-Time Analysis
        Analyzes total screen time for each day to identify high- and low-usage periods.
 2. App-Wise Usage Analysis
        Examines how much time users spend on individual applications and compares usage across different apps.
 3. Frequently Used Applications
        Identifies the applications with the highest usage and determines which apps contribute most to overall screen time.
 4. Usage Trends
        Analyzes changes in screen time and application usage over time to identify noticeable trends and patterns.
 5. Data Visualization
        Visualizations are used to make the findings easier to understand. Possible visualizations include:
               📊 Bar charts for app-wise usage
               📈 Line charts for daily screen-time trends
               🥧 Pie charts for usage distribution
               🔵 Scatter plots for relationships between usage-related variables

🚀 How to Run the Project
1. Clone the repository
git clone https://github.com/your-username/Screen-Time-and-App-Usage-Dataset.git

2. Navigate to the project directory
cd Screen-Time-and-App-Usage-Dataset

3. Install the required libraries
pip install -r requirements.txt
Or install them individually:
pip install pandas numpy matplotlib seaborn jupyter

4. Launch Jupyter Notebook
jupyter notebook
Open the analysis notebook and run the cells to reproduce the analysis and visualizations.
